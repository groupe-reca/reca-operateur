# `src/services`

Cas d'usage / orchestration : Authentication, Mission Loader, etc. Relient domaine +
persistance + intégrations pour réaliser une opération, sans contenir d'UI.

Exemple : `Authentication` (authentifier, vérifier le rôle, charger la mission assignée)
et `Mission Loader` (télécharger mission + MissionItems, préparer les objets du moteur).
